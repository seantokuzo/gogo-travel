## Standing rules

- Secrets never in git, never in context. `.env` is gitignored. The project `.env`
  deny rules apply only to sessions whose primary working directory is the repo root
  (project settings load from it; `/cd` changes it). There, `cat <file>` and
  `grep X <file>` were DENIED (canary 2026-10-04, Claude Code 2.1.289); per the docs
  `head`/`tail`/`sed`/`tee` and `<`/`>` redirects are covered too. **NOT covered:**
  unnamed reads (`grep -r X .` run in the holding dir read the canary file), scripts,
  and programs that name the file but aren't recognized file commands (`diff`, `awk`,
  `gh gist create`, … — unverified); `source` and the built-in Grep/Glob tools are
  unverified (Read rules reach those tools best-effort only). OS sandbox for loop
  runs: planned under B-29, not built.
- Auth, payments/split-money surfaces, migrations, and release workflows are
  **sensitive paths** — any blocking finding on them escalates the review.
- Money is integer cents (or `Decimal`) — never float.
