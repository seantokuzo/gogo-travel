## Standing rules

- Secrets never in git, never in context. `.env` is gitignored. The project `.env`
  deny rules apply only to sessions started at the repo root (project settings load
  from the primary working directory). There, `cat <file>` and `grep X <file>` were
  DENIED (canary 2026-10-04, Claude Code 2.1.289); per the docs `head`/`tail`/`sed`/
  `tee` and `<`/`>` redirects are covered too. **NOT covered:** unnamed reads
  (`grep -r` from a parent dir read the canary file), scripts, and programs that name
  the file but aren't recognized file commands (`diff`, `awk`, `gh gist create`, …
  — unverified); `source` is unverified. OS sandbox for loop runs: planned under
  B-29, not built.
- Auth, payments/split-money surfaces, migrations, and release workflows are
  **sensitive paths** — any blocking finding on them escalates the review.
- Money is integer cents (or `Decimal`) — never float.
